# novnc-trackpad
Simple trackpad addon script for noVNC

## How to use
1. Copy `trackpad.js` into your extracted noVNC folder (where `vnc.html` is located).
2. Add `<script src="trackpad.js"></script>` right before `</body>` in `vnc.html`.

## Gestures
- **1-finger drag:** Move cursor
- **1-finger tap / double-tap:** Left-click / double-click
- **Tap-then-drag** or **hold (~0.4s) + drag:** Click and drag
- **2-finger tap / drag:** Right-click / scroll
- **3-finger tap:** Middle-click
